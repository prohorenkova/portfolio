JavaScript

1. Scroll-reveal
Элементы с классом .reveal изначально скрыты (opacity, сдвиг, blur).

Через IntersectionObserver отслеживается появление блока в зоне видимости: добавляется класс visible, и CSS-переход плавно показывает контент.

Классы .reveal-delay-1 … .reveal-delay-5 задают задержку, чтобы блоки и карточки появлялись по очереди.


2. Галерея и lightbox
Клик по карточке открывает полноэкранный просмотр:

подставляется изображение выбранного проекта;
обновляются название, теги и счётчик (01 / 05);
прокрутка страницы блокируется.

Навигация:

кнопки { и } - предыдущий / следующий проект;
клавиши ← / → - то же;
Esc или клик по фону - закрытие.

При смене слайда изображение кратко затемняется (класс fade), затем загружается следующее.


3. Параллакс
Декоративные блоки .ascii-pattern слегка смещаются за курсором.

Скорость задаётся атрибутом data-speed - создаётся лёгкий эффект глубины.


4. Кнопка «наверх»
После прокрутки примерно на 400px элементу #backTop добавляется класс visible.

По клику страница плавно возвращается к секции «Обо мне».
